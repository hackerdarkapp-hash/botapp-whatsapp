# بوت تيليجرام بلوحة تحكم أدمن وقوائم متداخلة

## الوظائف
- تعديل نص الترحيب من داخل تيليجرام.
- تغيير صورة القائمة أو إزالتها.
- إضافة أزرار رئيسية وأزرار داخل قوائم فرعية.
- تغيير اسم الزر أو رابطه أو النص المرتبط به.
- حذف الأزرار والقوائم.
- تخزين الإعدادات في ملف `config.json` على القرص الدائم.
- الروابط الأصلية مضبوطة: الموقع، القناة، وحساب X.

## متطلبات Render
لأن إعدادات البوت تحفظ في ملف، يجب إضافة **Persistent Disk** إلى خدمة Render حتى لا تضيع الإعدادات عند إعادة النشر:
- Mount Path: `/var/data`
- Environment Variable: `DATA_DIR=/var/data`

## النشر
1. ارفع الملفات إلى GitHub.
2. أنشئ خدمة Background Worker أو خدمة Node.js تدعم عملية مستمرة.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. أضف متغيرات البيئة:
   - `BOT_TOKEN` = توكن BotFather
   - `ADMIN_ID` = رقم حسابك الرقمي في تيليجرام
   - `DATA_DIR` = `/var/data`
6. أضف Persistent Disk واجعل Mount Path هو `/var/data`.
7. انشر المشروع، ثم افتح البوت وأرسل `/start`.

## أوامر البوت
- `/start` عرض قائمة المستخدمين.
- `/admin` فتح لوحة التحكم (للأدمن فقط).
- `/myid` معرفة رقم حساب تيليجرام.
- `/cancel` إلغاء إدخال جارٍ.
- `/removephoto` حذف صورة القائمة (للأدمن فقط).

## إدارة الأزرار
من `/admin` > إدارة الأزرار:
- اختر زرًا لتغيير اسمه أو الرابط أو النص أو حذفه.
- أضف زرًا رئيسيًا، أو افتح قائمة فرعية ثم أضف أزرارًا بداخلها.
- نوع `url` يفتح رابطًا.
- نوع `submenu` يعرض قائمة فرعية قابلة للتعديل.
- نوع `text` يعرض نصًا عند الضغط.

## الأمان
لا تضع `BOT_TOKEN` داخل الملفات ولا ترفعه إلى GitHub. أضفه في Render Environment Variables فقط.
